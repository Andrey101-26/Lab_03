# Лабораторная работа №3: медиатека

Каталог фильмов, музыкальных произведений и аудиокниг. Python 3.10+.
ФИО и группу необходимо вписать перед сдачей.

## Установка и запуск в Windows / PyCharm

Откройте терминал в корне проекта. Используйте Python выбранного окружения:

```powershell
python -m pip install pytest ruff mypy
python -m pip install -e .
python -m media_catalog --help
python -m pytest
python -m ruff check .
python -m mypy src/media_catalog
```

Если окружение не активировано, вместо `python` используйте
`.\.venv\Scripts\python.exe`. После установки пакета допустим и запуск
`src/media_catalog/__main__.py` из PyCharm. Код `models.py` только описывает модель.

## Структура

- `models.py`: неизменяемый `dataclass Media`, проверка типов и значений.
- `catalog.py`: словарный индекс ID → Media, операции и протоколы.
- `storage.py`: функции `save_catalog(catalog, path)` и
  `load_catalog(path, catalog=None)`. При переданном каталоге загрузка заменяет
  его содержимое; без него возвращает новый каталог.
- `errors.py`: базовая `CatalogError` и пять предметных ошибок.
- `constants.py`: версия JSON.
- `__main__.py`: терминальные команды и точка входа.
- `tests/`: проверки модели, каталога, хранения и атомарности.

## Принятые правила

Media содержит `id`, `name`, `category`, `year`, `creator`, `minutes`.
Строки непустые после удаления внешних пробелов для проверки; исходный текст
сохраняется. Год и длительность — целые положительные числа; bool запрещён.
Год обозначает год выпуска/создания произведения. Дополнительные ограничения
на исторические даты не вводятся. Категория — произвольный непустой вид материала.
ID сравниваются точно, включая регистр и пробелы. Уникальность проверяет каталог.

Объекты неизменяемые (`frozen=True`), поэтому ID нельзя поменять после добавления.
Итерация идёт в порядке добавления. После удаления и повторного добавления
объект помещается в конец. Итератор работает со снимком коллекции.
Поиск категории точный; поиск имени — подстрока с `casefold()`, без учёта регистра.
Пустой поисковый запрос находит все объекты. Результаты — новые списки.

`get`, `add`, `remove`, проверка ID имеют среднюю сложность O(1) благодаря dict.
Поиск по имени и категории — O(n) по числу объектов (дополнительно учитывается
длина строк). Создание итератора-снимка требует O(n) времени и памяти.

## Формат JSON и атомарность

Корень: `{"format_version": 1, "items": [...]}`. Каждый элемент содержит все
шесть полей Media, порядок списка совпадает с порядком каталога.
Неизвестная версия вызывает UnsupportedVersionError. Ошибки синтаксиса,
структуры, полей, дубликаты и ошибки чтения вызывают CorruptFileError.
Документ сначала полностью загружается во временный каталог; исходное
состояние заменяется только после успеха. Это атомарность загрузки относительно
существующего каталога, а не гарантия атомарной записи файла на диск.

## Команды терминала

После установки пакета команды выполняются из терминала PyCharm:

```powershell
python -m media_catalog --help
python -m media_catalog add 001 "Солярис" "фильм" 1972 "Андрей Тарковский" 167
python -m media_catalog list
python -m media_catalog get 001
python -m media_catalog find --name "СОЛЯ"
python -m media_catalog find --category "фильм"
python -m media_catalog count
python -m media_catalog save backup.json
python -m media_catalog remove 001
python -m media_catalog load backup.json
```

Каталог автоматически читается из `catalog.json` в текущей папке и сохраняется
после добавления, удаления и успешной загрузки. Отсутствующий рабочий файл означает
пустой каталог. Повреждённый файл вызывает ошибку и не заменяется пустым.
Другой рабочий файл задаётся **перед командой**:

```powershell
python -m media_catalog --file my_library.json list
```

Успех: код выхода 0. Ошибка: сообщение в stderr и код 2.
`save` создаёт копию, `load` заменяет рабочий каталог из указанного JSON.
